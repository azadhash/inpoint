inpoint

Privacy

Last updated 29 October 2026

inpoint is a command-line tool and Claude Code plugin that runs entirely on your own computer. It has no server, no account, and no analytics. Its author never receives any data from it.

What it processes

When you point it at a Jira ticket, it reads that ticket and downloads its attachments to a folder on your computer. Video and audio files are transcribed on your computer. Frames are extracted on your computer. All results are written to the same local folder.

Network connections it makes

  • Your Jira site, to read the ticket and download attachments, using either an API token you created or your own browser session.
  • Hugging Face, once, to download Whisper model weights the first time they are needed. No data about you or your tickets is sent; it is a file download.
  • Apple, on macOS 26 and later, when the operating system installs its own speech recognition assets. Audio is processed on the device and is not sent to Apple by this tool.

Nothing else. No audio, transcripts, images, ticket content, or usage information leaves your computer.

Credentials

If you choose to use a Jira API token, it is stored in a file readable only by your user account, outside the plugin folder, and is sent only to your own Jira site. You can remove it at any time with inpoint logout.

Claude Code

When the plugin is driven by Claude Code, the text Claude reads back to you, such as a transcript, passes through Claude under Anthropic's own privacy terms, exactly as any other file you ask Claude to read would.
